🍎 CÁCH CHẠY TRÊN MAC:

BƯỚC 1: Cài Python
   → Vào python.org
   → Download Python 3.7 trở lên
   → Cài đặt

BƯỚC 2: Mở Terminal
   → Cmd + Space
   → Gõ "Terminal"
   → Enter

BƯỚC 3: Di chuyển vào thư mục
   cd ~/Desktop/Cambridge-Dictionary
   (hoặc đường dẫn nơi bạn giải nén)

BƯỚC 4: Cài thư viện
   pip3 install -r requirements.txt

BƯỚC 5: Chạy app
   python3 dictionary_gui.py

   → App sẽ mở lên!


⚠️  LƯU Ý:

   • Lần đầu chạy có thể lâu vì cài thư viện
   • Cần Internet để tra từ
   • File common_words.txt phải cùng thư mục


📚 TÍNH NĂNG:

   ✅ Tra từ từ Cambridge Dictionary
   ✅ Autocomplete 4795 từ
   ✅ Phát âm UK/US
   ✅ Dịch sang tiếng Việt
   ✅ Ghi nhớ từ vựng
   ✅ Export Excel cho Quizlet


💡 NẾU GẶP LỖI:

   Lỗi: "tkinter not found"
   → Cài: brew install python-tk

   Lỗi: "Permission denied"
   → Chạy: chmod +x dictionary_gui.py

   Lỗi khác:
   → Đảm bảo đã cài Python 3.7+
   → Chạy lại: pip3 install -r requirements.txt

🎯 BẠN CẦN BUILD APP CHO CẢ WINDOWS VÀ MAC:


CÁCH 1: GITHUB ACTIONS (TỰ ĐỘNG BUILD) ⭐⭐⭐⭐⭐
════════════════════════════════════════════════

   Bước 1: Tạo repository trên GitHub.com
   
   Bước 2: Double-click: push_to_github.bat
           → Nhập URL repository
           → Đợi push xong
   
   Bước 3: Vào GitHub → Tab "Actions"
           → Đợi build xong (5-10 phút)
   
   Bước 4: Download Artifacts:
           ✅ Cambridge-Dictionary-Windows.exe
           ✅ Cambridge-Dictionary-macOS.app
           ✅ Cambridge-Dictionary-macOS.dmg
   
   Bước 5: Chia sẻ:
           Windows: Gửi file .exe
           Mac: Gửi file .dmg


═══════════════════════════════════════════════════════════════

CÁCH 2: BUILD THỦ CÔNG
════════════════════════

   Windows (bạn đã có):
   ✅ dist\EnglishVietnameseDictionary.exe
   
   Mac (cần máy Mac):
   ❌ Cần build trên Mac
   → Đọc SETUP_GITHUB.md


═══════════════════════════════════════════════════════════════

📁 FILE CHIA SẺ HIỆN CÓ:
════════════════════════

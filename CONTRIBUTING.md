# 🤝 Contributing to Cambridge Dictionary

Cảm ơn bạn quan tâm đến việc đóng góp cho dự án!

## 🚀 Cách đóng góp

### 1. Fork repository
- Click nút "Fork" ở góc trên bên phải
- Clone fork về máy: `git clone https://github.com/YOUR_USERNAME/cambridge-dictionary.git`

### 2. Tạo branch mới
```bash
git checkout -b feature/your-feature-name
```

### 3. Thực hiện thay đổi
- Sửa code, thêm tính năng mới
- Test kỹ trước khi commit
- Tuân thủ coding style hiện tại

### 4. Commit và push
```bash
git add .
git commit -m "Add: mô tả ngắn gọn về thay đổi"
git push origin feature/your-feature-name
```

### 5. Tạo Pull Request
- Vào GitHub repository
- Click "Compare & pull request"
- Mô tả chi tiết về thay đổi
- Đợi review từ maintainer

## 📋 Guidelines

### Code Style
- Sử dụng Python 3.7+
- Tuân thủ PEP 8
- Comment code rõ ràng
- Tên biến/hàm có ý nghĩa

### Commit Messages
- Format: `Type: mô tả ngắn gọn`
- Types: `Add`, `Fix`, `Update`, `Remove`, `Refactor`
- Ví dụ: `Add: dark mode support`

### Testing
- Test trên Windows trước khi submit
- Kiểm tra tất cả tính năng hoạt động
- Test với file .exe được build

## 🐛 Báo lỗi

Khi báo lỗi, vui lòng cung cấp:
- Mô tả chi tiết lỗi
- Các bước tái tạo lỗi
- Screenshot (nếu có)
- Thông tin hệ thống (Windows version, Python version)

## 💡 Đề xuất tính năng

- Tạo issue với label "enhancement"
- Mô tả chi tiết tính năng muốn thêm
- Giải thích lợi ích cho người dùng
- Thảo luận với community trước khi code
